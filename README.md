## Signature Flavours

- **Mulberry Delight (₹95 / scoop)** — Wild forest mulberries simmered into rich compote and slow-folded into thick farm-fresh dairy cream.
- **Tender Coconut Malai (₹85 / scoop)** — Pure coconut water and sweet, tender coconut pulp (malai) churned with farm whole cream.
- **Ripe Pink Guava (₹85 / scoop)** — Fragrant ruby orchard guava puree folded into velvety cold-churned dairy gelato.
- **Fresh Sitaphal (₹85 / scoop)** — Seasonal custard apples, hand-deseeded daily to preserve luscious whole fruit segments.
